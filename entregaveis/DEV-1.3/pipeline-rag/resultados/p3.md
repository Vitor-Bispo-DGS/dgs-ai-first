## Cálculo de Frete Especial — 600 kg com destino a Manaus (Região Norte)

Com base na documentação disponível, segue o cálculo aplicável:

### Fórmula
**Valor do frete = Valor base × Multiplicador regional × Fator de peso**

### Parâmetros para este caso

| Parâmetro | Valor |
|---|---|
| Fator de peso (500kg–1.000kg) | **1,0** |
| Multiplicador regional – Norte | **1,8** |
| Valor base | Tarifa publicada na tabela mensal de fretes |

> **Exemplo:** Se o valor base for R$ 1.000,00 → Frete = R$ 1.000,00 × 1,8 × 1,0 = **R$ 1.800,00**

---

### ⚠️ Observações importantes

1. **Valor base não consta nos documentos indexados** — é necessário consultar a tabela mensal de fretes vigente para obter o valor final.
2. Como a carga tem **600 kg (acima de 500 kg)**, caso seja uma **carga perigosa**, aplica-se tabela específica da **PROC-043**, que atualmente está **em processo de revisão pelo Compliance** e pode sofrer alterações.
3. Cargas acima de **5.000 kg** exigiriam aprovação prévia do gerente de operações regional — não é o caso aqui.
